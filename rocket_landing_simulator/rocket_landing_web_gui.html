🎓 THEORY

2nd-Order ODE:

The rocket motion is governed by Newton's second law: F = ma, giving us z''(t) = -g + T(t)/m

State Variables:

z = altitude (position)
v = velocity (dz/dt)
a = acceleration (dv/dt)

Control Strategies:

Bang-Bang: Binary ON/OFF control based on velocity threshold. Simple but can oscillate.

PID: Smooth continuous control using Proportional, Integral, and Derivative terms for optimal performance.
